# altPMP: public research materials

Public companion repository for:

> **A unified optimal control framework for microgrid and electrified vehicle as multi-energy-storage systems**

**Authors:** Huy-Ngoc Duong, Linh Tran, Thanh Vo-Duy, Minh C. Ta, and Bao-Huy Nguyen

This repository provides the public documentation, generated figures, and simulation outputs associated with the study. The complete MATLAB implementation is maintained separately in a private repository so access can be reviewed individually.

## Public contents

- [`figures/`](figures/) — generated figures in PDF and PNG formats
- [`simulation-results/`](simulation-results/) — generated CSV and MAT result files
- [`RESULTS.md`](RESULTS.md) — guide to the published figures and outputs
- [`ACCESS_REQUEST.md`](ACCESS_REQUEST.md) — instructions for requesting source-code access

## Source-code availability

The full source package contains the MATLAB algorithms, case-study scripts, figure-generation scripts, input data, and complete result set. To request access, follow [`ACCESS_REQUEST.md`](ACCESS_REQUEST.md). Approval is at the repository owner's discretion.

## Requirements for the private package

The implementation was prepared for MATLAB R2024b or later and tested with MATLAB R2026a. No additional toolbox is required.
