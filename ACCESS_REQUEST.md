# Requesting access to the private source repository

Access to the complete MATLAB source package is reviewed individually.

## How to request access

1. Open an issue in this public repository using the title **Source access request**.
2. Include:
   - your full name;
   - your institution or organisation;
   - your GitHub username;
   - your intended research or educational use; and
   - a contact email address, if it is not visible on your GitHub profile.
3. Do not include confidential, sensitive, or proprietary information in the public issue.

## Review process

The repository owner reviews each request. If approved, the requester will receive a GitHub collaborator invitation to the private repository. Submitting a request does not guarantee access.

Approved users must not redistribute the private source, models, scripts, or data without written permission from the repository owner.
